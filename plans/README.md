# plans/

Это место для технических планов реализации функций.

## Правила

- **Один план = одна функция.** Не смешивай несколько несвязанных задач в одном файле.
- **Имя файла:** `YYYY-MM-DD-название-функции.md` (например, `2026-04-10-user-auth.md`).

## Структура плана

Каждый план делится на фазы. Статус фазы:
- `[ ]` — не выполнена
- `[x]` — выполнена

В конце каждого плана — итоговый блок:
- Реализована функция целиком или нет.
- Что осталось сделать (если не завершена).

## Обязанность агента

Любой агент, работающий с планом, **обязан его актуализировать**:
отмечать завершённые фазы `[x]`, дописывать что было сделано и что осталось.
